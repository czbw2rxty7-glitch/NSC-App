Stripe Setup
Go Live in 30 Minutes
1
Create Stripe account
Go to stripe.com — free to join. UK card fee: 1.4% + 20p per transaction.
2
Get your keys
Stripe Dashboard → Developers → API Keys. Copy pk_live_... (publishable) and sk_live_... (secret).
3
Update index.html
Find pk_test_51TUYvO8... near the top of the script in index.html and replace it with your pk_live_... key.
4
Add secret key to Netlify
Netlify → Site Configuration → Environment Variables → Add STRIPE_SECRET_KEY = your sk_live_ key.
5
Test with demo card
Card: 4242 4242 4242 4242 · Any future expiry · Any 3-digit CVC
Netlify Function Code
const stripe = require('stripe')( process.env.STRIPE_SECRET_KEY ); exports.handler = async (event) => { const { amount, description } = JSON.parse(event.body); const intent = await stripe.paymentIntents.create({ amount, currency: 'gbp', description }); return { statusCode: 200, headers: { 'Access-Control-Allow-Origin': '*' }, body: JSON.stringify({ clientSecret: intent.client_secret }) }; };
